# 蒸馏规范 · 给跑长视频的那个 AI 用

> 目的：把连麦录音变成能检索的判断依据，不是金句摘抄。
> 上一版 150 分钟只出 10 条，漏了一半以上。按下面收紧。

## 一条必须八个字段

```json
{
  "src": "av号",
  "at": "时间戳 mm:ss",
  "type": "13 型之一（见下）",
  "case": "他的处境：行业 + 阶段 + 数字（至少两个数）",
  "verdict": "他的判断：一句话说清是什么问题",
  "line": "分界线：什么条件下这个判断会反过来",
  "do": "今天能做完的一个动作，结果只有成或不成",
  "tags": ["概念关键词，2-3 个"]
}
```

**缺 `do` 就不算完成。** 判断不给动作，等于只捅不牵。

## 13 型（必须选一个，不许自创）

借力错认 / 层级错判 / 空转 / 图纸代替施工 / 身份定型 / 混账 / 被动语态 /
前半生抵押 / 无凭证权威 / 数钱失焦 / 好牌嫌弃 / 人头投票 / 原地

## 密度底线

每 10 分钟至少 2 条。150 分钟的视频，少于 30 条就是漏了。

中间地带也要收：那些"他说了半天但没给结论"的段落，往往是最好用的——
因为那正好是他自己也没想清的地方，标 `verdict: "未给判断"` 也有价值。

## 分界线的写法（最容易写歪的一条）

❌ 空话："要看具体情况"
❌ 换句话重复："情况不同判断不同"
✅ 可判："产品是自己的且已跑通 → 扩渠道；产品是别人的且没跑通 → 换产品"

**判据必须落在一个能查的东西上**：数字、所有权、时间、是否签过字。

## 遇到两种说法冲突

不要选一个，两个都记，然后标出来：

```
"conflict": "同一件事他 33:40 说该换，43:31 说别换，差别在货是不是自己的"
```

这种冲突对训练判断力最有用——它直接告诉你条件在哪。

## 数字不可信时

标 `待核`，不要当依据用。例：
- "自称月流水 800 万，未出示后台 → 待核"
- "纯利 6 位数与十几二十万口径冲突 → 待核"
