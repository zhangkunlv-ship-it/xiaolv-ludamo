# 反向对照 · 同一个问题，答案可以完全相反

> 收藏结论，下次遇到新情况就用错。
> 收藏条件，下次能自己判断。

每组三行：**A 情况这么判 → B 情况反过来判 → 分界线在哪。**
分界线就是这一组的全部价值。判断之前先问分界线，别问结论。

---

## 1. 增长停了，该不该换赛道

| | |
|---|---|
| **A 该换** | 品类本身在退（平台流量结构变了、需求被替代了），他换三个渠道都掉，同行整体在掉 |
| **B 不该换** | 只有他在掉，同行在涨；或者他换渠道就掉、回原渠道就回来 |
| **分界线** | **掉的是他，还是这一行所有人。** 一个人掉是方法问题，所有人掉才是赛道问题 |

## 2. 要不要降价抢量

| | |
|---|---|
| **A 该降** | 毛利厚（五成以上），产能有富余，客户对价格敏感且复购低——降了能换量，量能摊薄固定成本 |
| **B 不该降** | 毛利薄（两成以下），成本里有一半是固定的，客户回头率高——降了只是把利润让出去，量不会真涨 |
| **分界线** | **降价之后的新增单量，够不够补掉老客户的利润损失。** 算得出这个数才谈降不降 |

## 3. 要不要招人

| | |
|---|---|
| **A 该招** | 有稳定订单，流程已经写下来过，新人照纸能干活；他自己卡在重复劳动上 |
| **B 不该招** | 订单不稳，活全在他脑子里，问一句答一句；招来的人只会多一个人问他 |
| **分界线** | **你的活能不能写成一张纸。** 写得出来才招，写不出来先写纸 |

## 4. 要不要投流

| | |
|---|---|
| **A 该投** | 转化率已经过了及格线，单客终身价值算得出来，投出去能回本 |
| **B 不该投** | 转化率是个位数，详情页还没让人看懂，投出去是买曝光不是买客户 |
| **分界线** | **先有转化，再谈流量。** 转化不到及格线，投多少亏多少 |

## 5. 要不要扩品类

| | |
|---|---|
| **A 该扩** | 现有品类已经打透（复购稳、口碑稳），新品类共用同一批客户和同一套供应链 |
| **B 不该扩** | 现有品类还在试错期，新品类要重新建供应链、重新获客 |
| **分界线** | **新品类能不能用旧客户、旧货源。** 两样都要重建，就是开新公司，不是扩品 |

## 6. 要不要压货

| | |
|---|---|
| **A 该压** | 上游涨价在即或断供风险高，货是标准品不会过时，手里现金能撑住六个月 |
| **B 不该压** | 品类迭代快、有保质期、现金只够三个月——压货就是拿命换价差 |
| **分界线** | **货会不会烂，钱能撑几个月。** 会烂或撑不住，一律不压 |

## 7. 要不要合伙

| | |
|---|---|
| **A 该合** | 对方带来你没有且短期造不出来的东西（牌照、渠道、技术），且愿意写清退出条款 |
| **B 不该合** | 对方带来的只是钱或人手，这两样能借能雇；或者一谈退出就含糊 |
| **分界线** | **他带来的东西，能不能用钱或合同买到。** 买得到就别给股份 |

## 8. 要不要涨价

| | |
|---|---|
| **A 该涨** | 客户回头率高、替代品少、排队等货；涨完掉的是最挑价的那批，留下的更省心 |
| **B 不该涨** | 客户全靠比价来、替代品一堆、涨价就掉一半——先做出差异再谈价 |
| **分界线** | **客户是因为什么来的。** 因为价来的，涨价就是赶客；因为别的来的，涨价是筛客 |

## 9. 要不要开第二家店

| | |
|---|---|
| **A 该开** | 第一家连续几个月净利稳定，且不靠店主本人盯；流程、采购、排班都有纸 |
| **B 不该开** | 第一家刚过盈亏线，或者离了店主就乱——开第二家等于把第一个坑复制一遍 |
| **分界线** | **把店主抽走一周，第一家还转不转。** 转，才能开第二家 |

## 10. 要不要接大客户

| | |
|---|---|
| **A 该接** | 大客户占比不超过三成，账期可控，能带来背书或新品类 |
| **B 不该接** | 接下来会占到产能一半以上，账期长，还要求独家——这不是客户，是房东 |
| **分界线** | **他占你多少产能，你还有没有第二个客户。** 占到一半又没有备选，就是被套住 |

## 11. 要不要外包

| | |
|---|---|
| **A 该外包** | 这活标准化、可验收、不接触核心客户；外包省下的时间能用在能挣钱的事上 |
| **B 不该外包** | 这活的质量直接决定客户体验，或者它就是你唯一的差异点 |
| **分界线** | **这活是不是你的护城河。** 是，自己干；不是，包出去 |

## 12. 要不要做品牌

| | |
|---|---|
| **A 该做** | 已经有稳定复购、有毛利空间、能控货或能贴牌——品牌是把已有的信任存下来 |
| **B 不该做** | 还在靠比价卖货、货是别人的、复购没起来——这时候做品牌是给空壳刷漆 |
| **分界线** | **有没有复购和定价权。** 两样都没有，先卖货，别做牌子 |

---

## 怎么用

判断之前，先在这张表里找对应的一组，然后只问一句：

```
你属于 A 还是 B。判据是哪一个数。
```

他答不出来，就说明还没到能判的时候——先把这个数拿到，再谈结论。

**这一页比任何结论都耐用。** 结论会过期，分界线不会。
