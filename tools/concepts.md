# 学习线 · 改定义，不发名词

> 多数人学商业，学的是别人的词。词都会用，判断还是错。
> 因为"需求""流量""筹码"这几个词，他脑子里的解释从第一天就是错的。解释错，后面每一步推理都歪。

顺序固定：**先说哪里想错了 → 再给一个能用的解释 → 再给证据 → 最后让他自己对一遍。**

节奏：**他不问，你不倒。** 问一层答一层。一次只给一段，等他说继续。

---

## 一、十二个词，常见的理解多半不对

| 词 | 常见的错解 | 更准的理解 |
|---|---|---|
| **生意** | 有收入就算在做生意 | 三件事同时成立：你有能交付的东西、有人真金白银付过、条款你能定。缺一条就不算 |
| **供应链** | 生意里的后端物流 | 决定谁能定价的那一环。货在谁手上，价就谁定 |
| **需求** | 我判断有人会需要 | 已经有人为近似的东西付过钱。收到钱只是需求的副产品 |
| **产品** | 我卖的那件东西 | 需求的解法。解法不硬，买来的流量全是漏的 |
| **流量** | 多少人看见我 | 多少人看见之后留下来了。它是结果，由产品和内容决定 |
| **筹码** | 我手上的资源和钱 | 别人短期复制不了的东西。检验方法只有一个：能不能一个电话找到拍板的人 |
| **阶段** | 想做多大就做多大 | 三段：先不死、再站住、再放大。时间能压短，步骤不能跳 |
| **瓶颈** | 我卡住的那个地方 | 再往上一层。他说没人来，往往一查是货不在他手上 |
| **团队** | 我招来的人 | 筛出来的。选人比培养重要。能打的人自带系统 |
| **环境** | 我待在的地方 | 相当于操作系统。系统不兼容，装什么应用都卡 |
| **利润** | 售价减去成本 | 位置 × 需求硬度 × 定价权。任一项为零，利润就是零 |
| **学习** | 报班、上课、找机构 | 拆正在赚钱的同行。他们跑通的东西就是教材，榜单就是成绩单 |

## 二、先吃透这三个

### 1. 供应链：谁定价，谁拿走利润

| 你在哪一级 | 你挣什么 | 撑得住吗 |
|---|---|---|
| 卖别人的货 | 差价，价由别人定 | 别人换渠道，你就没了 |
| 贴自己的牌 | 品牌溢价归你 | 厂能给第二个人贴同样的牌 |
| 股权绑住工厂 | 一起挣 | 绑上了就分不开 |
| 自己有厂 | 全部利润 | 风险归你，利润也归你 |

每往上一级，利润从别人口袋挪到自己口袋。**至少走到贴牌**——有牌子，回头客才归你。

三连问：`东西是你的吗？你能改吗？你改了之后他能不能找别人？` 一条不满足就是没护城河。

### 2. 需求：先看有没有人付钱

| 从手里有的出发（错） | 从谁在付钱出发（对） |
|---|---|
| 我家有蜂场 → 蜂蜜应该能卖 | 谁在买蜂蜜 → 为什么买进口的 → 我比他好在哪 |
| 我认识一群人，能不能做点生意 | 这群人现在为哪件事花钱，花得不痛快的地方在哪 |

赚到钱之后走偏的根子：注意力从"谁的问题还没被解决"挪到了"怎么挣更多"。钱不是目标，钱是做对了一件事的收据。

听到"我有资源想做某件事"，第一句就问：**有没有人已经为它掏过钱？** 没有，这个资源今天的市场价就是零。

### 3. 阶段：能压缩，不能跳

```
第一段 先不死   只管一件事：现金。别谈品牌战略，先想下个月的钱从哪来
第二段 站住     只管两件事：货源 + 回头客。别扩张，先打透一个品类
第三段 放大     只管系统。别自己上手，搭个架子让别人跑
```

判断自己在哪：**利润来自别人的货，就在第一段；来自自己的货，第二段往上。**

学过程，别学结果。抄第三段的做法，没有前两段的肌肉，摔得比原来更狠。

## 三、剩下几个，速览

**产品**　生意不好，第一件该查的不是流量，是回头率。回头率差＝产品有问题；回头率好但做不大＝来客有问题。别弄反。产品够硬不用卖，客户替你卖；产品不硬，你在替平台卖广告。

**流量**　九成情况下量越大越不挣钱。没量不是原因，是结果——产品和内容撑不住。品类决定渠道：快消适合冲动型直播，高客单适合窄众私域。把快消那套搬到高客单上，等于把精品咖啡摆进便利店货架。

**筹码**　标准只有一条：**一个电话能不能直接找到拍板的人。** 能，算本钱；不能，那只是"认识"。学了三个月新工具不算（聪明人都能三个月学会）；在一个行当里待满十年算（九成人做不到）。本钱 = 待的时间 × 做的事有多稀缺。

**瓶颈**　症状在下游，根子在上游。从最上面往下查：货源 → 产品力 → 来客 → 成交 → 团队。最常见的误判是"我需要更多流量"，一查才发现货不在自己手上，根本没利润。

**团队**　两成人做出八成产出。转化率要从 5% 拉到 15%，靠换人，不靠培训。培训能补"不会"，补不了"不想"和"怎么教都教不会"。招人是概率活：招十个、试三个月、留两个，是正常比例，漏斗没法加速。

**环境**　你最近常来往的五个人，就是你的操作系统。五个都在焦虑负债，半年后你跟他们一样。换环境最便宜的办法：去一家正在赚钱的公司上班，不用学，泡在那个系统里。

**利润**　别盯利润，盯那三项：位置往上走、需求确认存在、定价权在你手里。利润自己会跟上来。

**学习**　卖爆的就是教材，榜单是成绩单，拆解是作业。研究正在赚钱的人，等于免费上最好的课，还不过时。

**人情换不来业绩**　公司是挣钱的组织，不是家。对人客气不会让人变能干。意愿和天赋上的窟窿，靠感动填不住。

## 四、十一条反直觉判断

| # | 判断 | 一句话 | 容易以为 | 其实 |
|---|---|---|---|---|
| 1 | 谁定价谁拿利润 | 货在谁手上利润就归谁 | 卖得好就是挣钱 | 货是别人的＝在替别人挣钱 |
| 2 | 先有付钱的人 | 确认有人付，再谈资源 | 有资源就是优势 | 没需求，资源价值是零 |
| 3 | 阶段不能跳 | 三段顺序不可逆 | 照抄他的做法我也行 | 抄的是第三段，缺前两段的肌肉 |
| 4 | 变量要压缩 | 任何生意只有两三个根变量 | 分析越全越专业 | 列十个变量＝一个根都没找到 |
| 5 | 本钱先于策略 | 没本钱别上桌 | 有想法加行动力就能干 | 桌上每个人都有本钱 |
| 6 | 环境是上限 | 身边的人就是你的系统 | 意志力能扛住环境 | 系统不兼容，应用直接闪退 |
| 7 | 人情换不来业绩 | 公司是挣钱的组织 | 对人客气他就会拼 | 感动填不住能力窟窿 |
| 8 | 动作大于说法 | 不比说的，比做的 | 说得有道理＝在做 | 说得最好的往往没在做 |
| 9 | 病在上游 | 他指的地方是症状，根子在上面 | 他说的就是问题 | 他说的都是症状 |
| 10 | 自己给自己攒 | 没人欠你，自己挣 | 没资源就做不了 | 人人都是空手起家，这很正常 |
| 11 | 答案在同行身上 | 研究赢家，免费学 | 学习＝花钱报班 | 最好的课在别人的后台里 |

## 五、五个能直接用的流程

### 流程 1 · 判一件事值不值得做

```
① 东西是你的吗？           不是 → 先去有，别往下走
② 在第几段？               跳步 → 回位
③ 有人已经付过钱吗？        没有 → 做一个能验证的动作
④ 根变量是哪两三个？        压不出来 → 你还没看懂
⑤ 卡在哪一层？从最上面查     找到了 → 只动那一层
⑥ 你手里有什么短期抄不走的？  没有 → 先攒
⑦ 别论证，做一个动作看数      没做 → 承认不想
```

### 流程 2 · 看清他在哪一档

```
动词是谁做的    "我在做/我试过" 还是 "我准备/我计划"
责任推给谁      外面（行业/平台/运气）还是自己（我没做/我选错）
数字有多粗      具体数 还是 "挺多/还行"
在讲事实吗      描述 还是 表演
```

### 流程 3 · 往链条上游走

```
零级  卖别人的货   → 只是渠道，不算生意人
一级  贴自己的牌   → 牌子是你的，回头客归你
二级  股权绑工厂   → 利益一致，一起挣
三级  自有工厂     → 完全控货，定价权就是利润权
```

### 流程 4 · 找卡点（从上往下，找到第一层有问题的就停在那修）

| 层 | 查什么 | 症状 | 怎么修 |
|---|---|---|---|
| 货源 | 东西是不是你的 | 有量没利 | 往上游走 |
| 产品力 | 回头率、退货率 | 有利但回头差 | 比对手好一档 |
| 来客 | 渠道配不配品类 | 回头好但做不大 | 高端私域 / 标品平台 / 冲动直播 |
| 成交 | 话术、信任、价格 | 有量不成交 | 三个里通常只有一个出问题 |
| 团队 | 有人能接你的手吗 | 有规模但你累死 | 搭架子 |

### 流程 5 · 用一个动作验证

```
① 定义一个动作：三天内能做完，结果只有成或不成
    不是"去了解" → 是"把链接挂上去"
    不是"问问熟人" → 是"找十个目标客户，问他们愿不愿现在付钱"
② 做。不等准备好。
③ 看数。数回来之前不讨论。
④ 好 → 继续。不好 → 换一个再测。三个都不行 → 换方向。
```

## 六、学完让他自查（逐条打勾，不许含糊）

**生意这块**
- [ ] 东西是你的吗？（不是＝在替别人卖）
- [ ] 在链条哪一级？（卖别人的／贴牌／股权／自有）
- [ ] 从手上有啥出发，还是从谁在付钱出发？
- [ ] 在第几段？（利润来自别人的货＝第一段）
- [ ] 根变量是哪两三个？压到硬事实了吗？
- [ ] 卡点在上面哪一层？从最上面查过了吗？

**本钱这块**
- [ ] 有什么是别人短期追不上的？
- [ ] 在一个方向上待了多久？（不到三年，本钱还没长出来）

**环境这块**
- [ ] 最近常来往的五个人，平均什么状态？
- [ ] 你的环境是焦虑型、赚钱型，还是干活型？

**执行这块**
- [ ] 说想做的东西，已经在做了吗？（没做＝不想）
- [ ] 上次"研究方向"花了多久？做过一个三天能完成的验证动作吗？
- [ ] 团队里出活的和不出活的比例？不出活的调开了吗？

**学习这块**
- [ ] 想学的东西，先拆过这行里前一百个赚钱的人吗？

## 七、学完必须收口

学完不收口＝白学。收法只有一个：把他推回自己的事上。

```
道理到这儿。要不要拿你手上那件事，照着走一遍？你说，我听着。
```

他说要 → 转判断线（`SKILL.md` 第 2 步），把刚学的两三个关键词带上。
判断时对照一句：**「你刚学了这个。你刚才说的每个字都跟它反着。自己听一遍。」**

这一句比任何总结有用。
