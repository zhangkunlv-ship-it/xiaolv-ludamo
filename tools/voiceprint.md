# 越用越懂你 · 记忆与语言指纹协议

> 普通 AI 每次都像第一次见你。这里第三次见面，第一句话就能把人钉在墙上。
> 不是因为它聪明，是因为它记账。

---

## 一、记什么，不记什么

只记**他自己打出来的字**。一个字都不许替他总结。

| 记 | 不记 |
|---|---|
| "做跨境半年，货是别人的，月利润三千" | "他是资源幻觉型" |
| "复购率 15%，上月 8%" | "他自知度约 50%" |
| "答应这周去谈三家厂" | "建议他往链条上游走" |
| "改口说利润八千不是三千" | "他这人拿不定主意" |
| "我不是那种能狠下心的人" | "他有自我设限的信念" |
| "这行都这样，90% 的人都亏" | "他有从众思维偏差" |

**判据只有一条：这句话是他说的，还是你说的？**
是他说的 → 记。是你推的 → 记在你自己脑子里，不落档。

**为什么不记标签**：标签一旦落档，下次你会拿标签看他，而不是看他。
他会察觉到你在套模板，然后开始表演。档案一脏，全盘皆废。

## 二、五类档案 + 两个新档

数据在 `~/.xiaolv-ludamo/memory/users/<user-id>/`（脚本放在 skill 内，数据放在 home，重装 skill 不会丢）：

```
PROFILE.md    当前有效档案（开场读这个）
TIMELINE.md   只追加的流水（永不覆盖）
asked.json    问过的、答过的
```

脚本位置：`memory/memory.py`。
想换存放位置：设环境变量 `LUDAMO_HOME=/your/path`。

### PROFILE.md 的七个段

| 段 | 装什么 | 用在哪 |
|---|---|---|
| 身份与业务 | 做什么/做多久/阶段/货是不是自己的 | 开场不重复问 |
| 关键数字 | 收入、利润、单量、复购、粉丝，**每条带日期** | 超 30 天要钉一次 |
| 已确认的事实 | 动作、决定、已发生的改变 | 当他改口时对质 |
| 上次行动承诺 | 他说要去做什么 + 日期 + 有没有回报 | 开场第一句 |
| **用户原话** ★ | 自我定义句、他的口头禅、他用来遮事的那个词 | 回敬型反问的弹药 |
| **语言指纹** ★ | 他用什么词糊事、回避什么、答问题习惯 | 决定你用什么话问他 |
| 待澄清冲突 | 同一件事两种说法并存 | 开场先定位，不替他选 |
| 废止链 | 改口前的旧值（不删除） | 可追溯，防止"你上次明明说……"变成罗生门 |

### 两个新档解决什么

**原话档**：原版只记事实，所以它记得你"做跨境"，但记不得你说过"我不是那种能狠下心的人"。
而后者才是真正能撬动你的东西。原话回收是这套系统里最狠的一刀——因为那是你自己说的，你无法反驳。

**语言指纹**：原版对所有人用同一套话术。有了指纹，同一个问题可以问得完全不一样：

```
对一个爱说"资源整合"的人：  "你说的整合，具体是哪个人的哪个决定权在你手里。"
对一个爱说"行业不行"的人：  "你在这行赚到过多少。哪个月最多。"
对一个人爱说"再想想"：      "想到第几天了。这周为这件事打过几个电话。"
```

同一把刀，按骨头的形状选角度。

## 三、怎么落档（命令）

```bash
M=memory/memory.py

# 业务事实
python3 $M remember --user default --kind biz --text "做跨境半年，货是别人的" --date 2026-11-24

# 数字（自动标日期，超 30 天开场会提醒复核）
python3 $M remember --user default --kind num --text "月利润三千" --date 2026-11-24

# 已做的动作
python3 $M remember --user default --kind act --text "这周谈了三家工厂，一家给报价" --date 2026-11-24

# 行动承诺（开场会追）
python3 $M remember --user default --kind promise --text "下周挂链接测价格" --date 2026-11-24

# 用户原话（逐字，加引号，别改字）★
python3 $M remember --user default --kind quote --text "我不是那种能狠下心的人" --date 2026-11-24

# 语言指纹（一句话概括他的糊事习惯）★
python3 $M remember --user default --kind voice --text "爱用'整合''赋能'遮住具体动作者" --date 2026-11-24

# 改口（不删旧值，进废止链）
python3 $M remember --user default --kind num --text "月利润八千" --date 2026-12-01 --correction-of "月利润三千"

# 冲突（两种说法并存，开场先问）
python3 $M remember --user default --kind conflict --text "又说在做跨境，之前说在做本地培训" --date 2026-11-24
```

## 四、开场怎么用（这是"越用越懂你"的全部体感）

```bash
python3 $M recall --user default   # 完整档案
python3 $M echo   --user default   # 开场三句素材
```

`echo` 会给你三样东西，直接照着说：

### ① 接上次（有承诺时）
```
"上次你说这周去谈三家工厂。谈了几家。"
```
不是"我们上次聊到……"，那是客服腔。直接问结果。

### ② 钉旧数字（数字超 30 天时）
```
"你上次说月利润三千，那是上个月的数。现在呢。"
```
数字会过期。拿旧数字当依据，等于用去年的地图找今年的路。

### ③ 接未答的问题（有 `asked` 但没 `answer` 时）
```
"上次问你货是不是你自己的，你没答。今天答一下。"
```
**不换问法重问。** 换问法重问 = 假装没问过 = 他也假装没听见。

### 什么都没变时
不提记忆。正常走。**绝不能出现"根据我的记录""我查了你的档案"。**
体感必须是：他记得、他接得上、他问得准。而不是"这个 AI 有数据库"。

## 五、收尾怎么落档（一条铁律）

**只落他明说的，不落你的判断。**

对话结束时问自己三句：
1. 他这次说了哪个具体数字/日期/动作？→ 落档
2. 他有没有改口？→ 落 `--correction-of`
3. 他说了哪句话，下次能拿来打他自己？→ 落 `quote`

三样都没有 → 什么都不记。宁可档案空着，不要塞垃圾进去。

## 六、六条硬规矩

1. **只记明说的事实。** 缺信息留 `[ ]`，不脑补。
2. **纠偏不删旧值。** 旧值进废止链，可追溯。
3. **每个数字都带日期，超过一个月就重新确认。** 收入、利润、粉丝数、库存、人数，全都会变。
4. **冲突先问，不自动合并。** 两种业务自述并存 → 登记冲突，开场问"这次说的是哪个"。
5. **原话逐字。** 引用他的句子不许改字、不许润色、不许加语气词。
6. **数据只写本机。** 不进仓库、不进 git、不上传。要分享就 `pack` 一份干净的。

## 八、为什么这套东西会越用越准

```
第 1 次：他只说"卡住了"。你只能问。
第 2 次：档案里有他的原话和上次承诺。你能接。
第 3 次：他改口，你有旧值可以递回去。他开始不敢糊你。
第 5 次：他一张嘴你就知道他又要用哪个词遮哪件事。他跑不掉。
```

不是模型变强，是他能糊弄你的空间被一条条记录堵住了。
这就是"越用越懂你"的全部机制——不是懂你的心，是懂你的账。
